# 港粵跨境接送 - Pricing & Locations Migration

## 📋 說明
本 migration 新增：
1. `pricing_rules` 表：港粵熱門路線行情價（後台可調）
2. `locations` 表：內建 POI（機場/口岸/商場/車站/飯店）
3. `orders` 表擴充：詳細地址、座標、估算價
4. `get_pricing_estimate` RPC：前端呼叫估算價

## ⚠️ 必要步驟

### Step 1：執行 migration（建立表 + RPC + RLS）
到 Supabase Dashboard → SQL Editor → New query，貼上並執行：
```
supabase/migrations/20260930_pricing_and_locations.sql
```

### Step 2：執行 seed（內建 POI + Pricing 行情）
同上，貼上並執行：
```
supabase/seed_locations_and_pricing.sql
```

### Step 3：（可選）設定 SUPABASE_DB_URL
若要走 `scripts/run-migration.mjs` 自動跑，需要到
Supabase Dashboard → Project Settings → Database → Connection string → Session pooler
複製 connection string，加到 `.env.local`：
```
SUPABASE_DB_URL=postgres://postgres.vuuamydahzhpajjdvokl:[YOUR-PASSWORD]@aws-0-[region].pooler.supabase.com:5432/postgres
```
