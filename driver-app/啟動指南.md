# 🚀 司機管理後台啟動指南

## 問題：ERR_CONNECTION_TIMED_OUT

這是因為 `driver-app/` 還沒安裝依賴（沒有 `node_modules`）。

## ⚠️ 重要：為什麼分兩個 Next.js 項目？

```
project_prd.md/
├── app/           ← 乘客端 (port 3000)  ← 已有 node_modules
└── driver-app/    ← 司機端 (port 3001)  ← 還沒有，需要安裝
```

每個 Next.js 項目都需要**自己的** `node_modules`。

## 📋 啟動步驟（需要打開 2 個終端）

### 終端 1：乘客端（已有，繼續運行）

```bash
cd "C:\Users\weiji\.cursor\project_prd.md"
npm run dev
```
訪問 `http://localhost:3000`

### 終端 2：司機端（新）

```bash
cd "C:\Users\weiji\.cursor\project_prd.md\driver-app"
npm install
npm run dev
```

成功後看到類似：
```
▲ Next.js 16.3.5
- Local:        http://localhost:3001
✓ Ready in 3.2s
```

## 🌐 訪問司機端

- 司機登入：`http://localhost:3001/driver/login`
- 司機中心：`http://localhost:3001/driver/dashboard`
- 搶單鏈接：`http://localhost:3001/grab/[token]`

## 🔍 故障排查

| 錯誤 | 原因 | 解決 |
|------|------|------|
| ERR_CONNECTION_TIMED_OUT | port 3001 沒啟動 | 執行上面的步驟 |
| Cannot find module 'next' | 沒安裝依賴 | 先 `npm install` |
| EADDRINUSE: port 3001 busy | 3001 被佔用 | 改 `package.json` 的 port 或關掉佔用進程 |

## ❓ 確認這是「網頁」而不是「app」

✅ 我建立的 `driver-app/` 是**網頁應用**（使用 Next.js）
✅ 司機用瀏覽器訪問 `localhost:3001` 就能用
✅ 不需要開發任何手機 app
✅ 兩個網頁完全獨立（不同的 port、不同的文件夾、不同的依賴）
