# 钉钉机器人配置指南

## 🎯 目标
实现订单自动推送到钉钉群，司机点击链接抢单。

---

## 📱 第一步：下载钉钉（如果还没有）

### Android / iOS
- 在应用商店搜索"钉钉"或"DingTalk"
- 或访问：https://www.dingtalk.com/

### 注册账号
- 用手机号注册
- 完成实名认证

---

## 👥 第二步：创建钉钉群（5分钟）

### 1. 创建群组
1. 打开钉钉 App
2. 点击右上角 **+** → **发起群聊**
3. 选择"**普通群**"
4. 群名称：`跨境专车司机群`
5. 邀请司机加入（或先自己测试）

### 2. 添加自定义机器人
1. 进入群聊
2. 点击右上角 **...（更多）**
3. 选择"**群设置**"
4. 找到"**智能群助手**" → "**添加机器人**"
5. 选择"**自定义**"机器人
6. 机器人名称：`订单通知`
7. **安全设置**选择："**自定义关键词**"
   - 填写关键词：`新订单`
   - （这样只有包含"新订单"的消息才会发送）

8. 点击"**完成**"
9. **复制 Webhook 地址**（非常重要！）
   ```
   https://oapi.dingtalk.com/robot/send?access_token=xxxxx
   ```

---

## 🔑 第三步：配置环境变量（2分钟）

### 编辑 `.env.local` 文件
```env
# Supabase 配置
NEXT_PUBLIC_SUPABASE_URL=你的Supabase项目URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=你的Supabase匿名密钥

# 应用配置
NEXT_PUBLIC_APP_URL=http://localhost:3000

# 钉钉机器人 Webhook（替换成你刚才复制的）
DINGTALK_WEBHOOK_URL=https://oapi.dingtalk.com/robot/send?access_token=xxxxx
```

## 🔒 安全设置说明

### 为什么选择"自定义关键词"？
1. **防止滥用**：只有包含关键词的消息才能发送
2. **简单安全**：无需 IP 白名单或签名验证
3. **推荐关键词**：`新订单`、`订单通知`、`抢单`

### 其他安全选项
- **加签验证**：更安全，但需要额外代码
- **IP 白名单**：适合固定服务器

## ❌ 常见问题

### Q1: 没有收到测试消息？
**检查清单**：
- ✅ Webhook URL 复制完整（包含 access_token）
- ✅ 消息包含关键词"新订单"
- ✅ 机器人没有被移除

### Q2: 提示"签名验证失败"？
- 确认选择的是"**自定义关键词**"，不是"加签"

### Q3: 消息格式乱了？
- 钉钉支持 Markdown 格式
- 检查换行符和特殊字符

### Q4: 想改机器人头像？
- 群设置 → 智能群助手 → 找到机器人 → 编辑

## 🎨 进阶：自定义消息样式

### Markdown 支持
```markdown
# 一级标题
## 二级标题
**粗体文字**
*斜体文字*
[链接文字](https://example.com)
> 引用文字
- 列表项
```

### 消息类型
```javascript
// 1. 文本消息
{
  "msgtype": "text",
  "text": {
    "content": "简单文本"
  }
}

// 2. Markdown 消息（推荐）
{
  "msgtype": "markdown",
  "markdown": {
    "title": "订单通知",
    "text": "**新订单**\n起点：香港"
  }
}

// 3. 链接消息
{
  "msgtype": "link",
  "link": {
    "text": "点击查看订单详情",
    "title": "新订单",
    "messageUrl": "https://example.com/grab/123"
  }
}
```

## 📊 监控与调试

1. 群设置 → 智能群助手
2. 点击机器人名称
3. 查看"**消息记录**"

- 每个机器人：**每分钟最多 20 条**
- 超出限制会被限流

## 🔄 更新 Webhook

### 如果需要更换 Webhook
1. 群设置 → 智能群助手
2. 移除旧机器人
3. 添加新机器人
4. 更新 `.env.local` 中的 `DINGTALK_WEBHOOK_URL`
5. 重启服务器
