# 🚀 企业微信机器人 - 5分钟快速配置

## ✅ 准备工作

你需要：
- ✅ 一个微信账号
- ✅ 5 分钟时间

**费用**：完全免费 ❌ 无需任何费用

---

## 📱 步骤 1：注册企业微信（2分钟）

### 如果你还没有企业微信：

1. 访问 https://work.weixin.qq.com/
2. 点击「立即注册」
3. 选择「企业/团队」
4. 填写信息：
   ```
   企业名称：港中专车
   管理员姓名：你的名字
   手机号：你的手机号
   ```
5. 微信扫码验证
6. 注册完成！✅

### 如果你已有企业微信：
直接跳到步骤 2

---

## 💬 步骤 2：创建群聊（1分钟）

1. 打开企业微信 App（手机/电脑都可以）
2. 点击右上角「+」→「发起群聊」
3. 可以暂时创建空群，或邀请几个测试成员
4. 群名称：**港中专车 - 订单推送群**
5. 创建完成！✅

---

## 🤖 步骤 3：添加群机器人（1分钟）⭐ 关键步骤

1. 在刚才创建的群聊中，点击右上角「···」
2. 点击「群机器人」
3. 点击「添加机器人」
4. 填写机器人信息：
   ```
   机器人名称：订单通知助手
   （可以上传头像，也可以跳过）
   ```
5. 点击「添加」
6. ⚠️ **重要**：复制 Webhook 地址

**Webhook 地址格式**：
```
https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**⚠️ 注意**：这个地址很重要，请保存好！

---

## ⚙️ 步骤 4：配置项目环境变量（1分钟）

### 方法 1：创建新文件（如果还没有 .env.local）

在项目根目录创建 `.env.local` 文件：

```bash
# 企业微信 Webhook（必需）
WECHAT_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key

# 网站域名（用于生成抢单链接）
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# Supabase 配置（稍后配置，暂时留空）
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```

### 方法 2：编辑现有文件

如果你已有 `.env.local`，只需添加/更新这一行：

```bash
WECHAT_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key
```

**替换 `你的key`** 为步骤 3 中复制的完整 Webhook 地址！

## ⚠️ 常见问题

### Q1: 找不到「群机器人」选项？
**A**: 确保你使用的是企业微信，不是普通微信。企业微信图标是蓝色的。

### Q2: 提示 "errcode: 93000"
**A**: Webhook URL 无效，请重新添加群机器人并获取新的 URL。

### Q3: 测试脚本提示"未配置 WECHAT_WEBHOOK_URL"
**A**: 
1. 确认 `.env.local` 文件在项目根目录
2. 确认文件内容格式正确（没有多余空格）
3. 重启开发服务器 `npm run dev`

### Q4: 消息发送成功但群里没收到
**A**: 
1. 检查机器人是否被移除
2. 检查群聊是否被解散
3. 尝试在企业微信群设置中重新添加机器人

### Q5: 想要多个群接收通知怎么办？
**A**: 可以配置多个 Webhook URL：
```bash
WECHAT_WEBHOOK_URL=url1,url2,url3
```
然后修改代码循环推送（需要自定义）
